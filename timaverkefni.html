Tímaverkefni: Arrays, map, filter & reduce

Verkefnið er tilbúið til að prófa. Verkefni 1–6 eru grunnurinn, 7 er aukaáskorun. Reynið að nota map, filter og reduce í stað for-loopu þar sem það passar.

Festist þú? 1. Lestu villuna í console. 2. Bættu við console.log() til að sjá gildin. 3. Spurðu sessunautinn. 4. Réttu upp hönd.

Verkefni 1: Nafnalisti

Skrifaðu nafn og smelltu á „Bæta við“. „Fjarlægja síðasta“ tekur síðasta nafnið af listanum. Sama nafn má ekki koma tvisvar.

Verkefni 2: Verð með VSK

Hér eru verð án virðisaukaskatts:

const verdAnVsk = [1290, 450, 3990, 790, 2490];

Búðu til nýtt fylki með verðunum með 24% VSK og birtu það. (Dæmi: 1000 → 1240)

Verkefni 3: Listi á síðuna

Birtu borgirnar sem lista á síðunni:

const borgir = ["Reykjavík", "Akureyri", "Ísafjörður", "Egilsstaðir", "Vestmannaeyjar"];

    Verkefni 6: Vörulisti

    Hér er fylki af objects. Hver vara hefur nafn og verd (náið í með vara.nafn og vara.verd). 

    const vorur = [
  { nafn: "Mjólk", verd: 229 },
  { nafn: "Brauð", verd: 649 },
  { nafn: "Ostur", verd: 1890 },
  { nafn: "Epli", verd: 399 },
  { nafn: "Kaffi", verd: 1490 },
  { nafn: "Súkkulaði", verd: 349 },
];

    Sláðu inn hámarksverð. Sýndu bara vörur sem kosta það eða minna, og samtals verð þeirra.

      Verkefni 7: Aukaáskorun 🌟 Orðagreining

      Skrifaðu setningu. Birtu síðan:

      • hversu mörg orð eru í setningunni
      • lengsta orðið
      • öll orð sem eru lengri en 4 stafir, með HÁSTÖFUM

      Vísbending: "hæ hó jibbí".split(" ") gefur fylkið ["hæ", "hó", "jibbí"]. Og ord.toUpperCase() breytir orði í hástafi.
